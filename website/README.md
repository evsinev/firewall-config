# firewall-config documentation site

[Astro](https://astro.build) + [Starlight](https://starlight.astro.build), published to
<https://evsinev.github.io/firewall-config/> by `.github/workflows/docs.yml` on every push to
`master` that touches `website/**`.

Pages live in `src/content/docs/`; the file name becomes the route. The sidebar sections
`Configuration`, `Generators`, `Reference` and `Internals` are autogenerated from the matching
sub-directories, ordered by the `sidebar.order` value in each page's frontmatter.

```
src/content/docs/
├── index.mdx  installation.mdx  quick-start.mdx
├── configuration/    the YAML input format
├── generators/       one page per generated artifact
├── reference/        CLI and YAML schema tables
└── internals/        architecture, rule derivation, known limitations
```

Every example on the site comes from [`examples/demo-network`](../examples/demo-network) in this
repository, so snippets and generated output can be re-verified by running the tool.

## Commands

| Command           | Action                                      |
|:------------------|:--------------------------------------------|
| `npm install`     | Install dependencies                        |
| `npm run dev`     | Dev server at `localhost:4321/firewall-config` |
| `npm run build`   | Production build to `./dist/`; fails on broken internal links |
| `npm run preview` | Preview the production build locally        |
